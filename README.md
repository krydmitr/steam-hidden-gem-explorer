Steam Hidden Gem Explorer

How to run:
Install Python https://www.python.org/downloads/
install dash, plotly, pandas, numpy
pip install -r requirements.txt

run either run_app.bat or run_app.sh
or just python steam_vis.py

it will say 
Dash is running on http://127.0.0.1:8050/
after that, just open the link in the browser.




The visualization is interactive, you can put your own tag in if you want to filter the plots. You can zoom in on required parts and there is a tooltip if needed when hovering over.

Dataset source:
FronkonGames, Steam Games Dataset, Kaggle.
https://www.kaggle.com/datasets/fronkongames/steam-games-dataset/data
